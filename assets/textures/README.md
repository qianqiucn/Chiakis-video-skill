# Bundled 2D Textures (CC0)

Zero-dependency 2D film grain, dust particles, paper, and washi overlays ready for Canvas 2D / CSS `mix-blend-mode` compositing.

| Folder | Files | Recommended Blend Mode & Opacity |
|---|---|---|
| `grain/` | `grain_fine_2048.png`, `grain_film35_2048.png` | `overlay` or `soft-light`, opacity `0.06–0.14`, tile/shift per frame |
| `dust/` | `dust_01..04_3840x2160.png` | `screen`, opacity `0.15–0.35`, alternate/rotate on 2s or 4s |
| `paper/` | `Paper001_4K_color.jpg` | `multiply` (on light grounds) or `overlay` (on dark), opacity `0.10–0.22` |
| `washi/` | `washi_solid_12.png`, `washi_solid_14.png` | `multiply` / `soft-light`, organic paper/editorial/ink PVs |
